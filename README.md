# 更新控 (Update Junkie)

**更新控** 是一款专注于管理和追踪 Android 应用安装来源的实用工具。通过集成的权限管理（Shizuku），它可以精确还原每个应用的“真实”安装渠道，帮助您理清应用的来龙去脉。

## 🚀 核心功能

- **深度安装来源识别**：
    - **打破“安装程序”迷雾**：不仅仅显示“软件包安装程序”，更能挖掘出其背后的发起者（如 **Google Chrome**、**系统浏览器** 等真实下载源）。
    - **优先级逻辑**：智能识别 `Originating`（原始来源）与 `Initiating`（发起者），确保展示对用户最有意义的来源。
- **流畅的增量加载**：
    - **流式扫描 (Flow)**：解析完一个显示一个，彻底告别长时间的 Loading 等待。
    - **实时进度追踪**：顶部进度条实时显示扫描数值（如 `45 / 210`），并伴有平滑的进度动画。
- **多渠道市场跳转**：一键跳转到 Google Play、酷安、小米、华为等主流市场进行更新。
- **Shizuku 深度集成**：利用 Shizuku 权限执行 `dumpsys package` 等系统命令，在无需 Root 的情况下获取受限的底层安装信息。
- **现代化交互设计**：基于 Material 3 规范，优化的触摸目标与视觉层级，带来流畅的视觉体验。

## 🛠️ 技术栈

- **Jetpack Compose**：全响应式 UI 构建。
- **Material 3**：Google 最新设计语言。
- **Shizuku API**：实现底层权限调用的核心方案。
- **Kotlin Flow & Coroutines**：实现非阻塞的增量扫描逻辑。
- **Reflective System Calls**：针对不同 Android 版本的系统服务调用方案。

## 📋 系统要求

- **Android 版本**：Android 7.0 (API 24) 及以上。
- **核心组件**：必须运行并授权 [Shizuku](https://shizuku.rikka.app/) 才能获取深度来源信息。

## 💡 使用小贴士

由于获取安装来源涉及到系统级命令调用（`dumpsys`），在应用较多时扫描可能需要数秒时间。我们已优化为**增量加载**模式，您可以在扫描过程中直接浏览已加载的应用。
