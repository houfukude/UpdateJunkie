# 更新控 (Update Junkie)

**更新控** 是一款专注于管理和追踪 Android 应用安装来源的实用工具。通过集成的权限管理（Shizuku / Root / ADB），它可以精确获取每个应用的安装渠道，并提供一键跳转至对应应用市场的功能。

## 🚀 核心功能

- **应用列表浏览**：查看设备上所有已安装的应用，包括系统应用。
- **安装来源识别**：自动识别应用是从 Google Play、酷安、小米、华为等主流市场安装的，还是通过外部安装程序（如 APK 管理器）安装的。
- **多重授权支持**：
    - **Shizuku**：推荐的授权方式，无需 Root 即可执行高权限操作。
    - **Root**：为已植根的设备提供完整支持。
    - **ADB**：支持通过 ADB 指令获取必要信息。
- **市场快速跳转**：发现应用有更新或需要查看详情时，一键跳转到对应的应用市场页面。

## 🛠️ 技术栈

- **Jetpack Compose**：现代化的原生 UI 框架。
- **Material 3**：遵循 Google 最新的设计规范。
- **Shizuku API**：实现无根高权限调用的核心依赖。
- **Kotlin Coroutines**：高效的异步任务处理。

## 📋 系统要求

- **Android 版本**：Android 7.0 (API 24) 及以上（本项目配置 minSdk 24）。
- **授权工具**：建议安装 [Shizuku](https://shizuku.rikka.app/) 以获得最佳体验。

## 🛠️ 开发与构建

1. 克隆仓库。
2. 使用 Android Studio (Ladybug 或更高版本) 打开项目。
3. 确保你的开发环境已配置好 JDK 17+。
